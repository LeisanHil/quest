# Может, прогуляемся?

Статический городской квест для Полины в Барселоне.

## Технологии

- Vanilla HTML, CSS и JavaScript — без сервера и базы данных.
- Скрипты на встроенном Node.js — только для локальной разработки и подготовки папки для публикации.
- Папка `dist/`, создаваемая сборкой, содержит готовый сайт для GitHub Pages.

## Локальный запуск

Требуется Node.js 14+ (лучше актуальная LTS-версия).

```bash
npm install
npm run dev
```

Скрипт выведет локальный адрес, обычно `http://localhost:5173`.

## Проверка и сборка

```bash
npm run check
npm run build
npm run preview
```

`npm run build` создаёт самодостаточную статическую папку `dist/`.

## Публикация

Каждый push в `main` запускает `.github/workflows/pages.yml`: проверка, сборка и публикация `dist/` на GitHub Pages.

- Лендинг: https://leisanhil.github.io/quest/
- Квест: https://leisanhil.github.io/quest/quest/

На локальном сервере это соответственно `/` и `/quest/`. Путь к корню сайта определяется автоматически, поэтому сохранённые ссылки работают и локально, и на GitHub Pages.

## Геолокация

Браузер запрашивает разрешение на геолокацию по действию участницы. Расстояние до очередной точки вычисляется на устройстве; допустимый радиус — 80 м.

Поскольку приложение полностью статическое, ответы и координаты доступны в публичном исходном коде, а проверку местоположения можно обойти технически. Это дружеский квест, а не система защиты результатов.

## Структура

```text
index.html                лендинг
quest/index.html          вход в квест
quest/history/index.html  просмотр прошлых загадок
src/main.js               навигация и механика
src/quest-data.js         загадки, ответы и точки маршрута
src/styles.css            общий стиль
src/landing.css           стиль лендинга
public/                   изображения
```

Ссылка на финальный подарок пока не задана; она добавляется в `src/quest-data.js`.
