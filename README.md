# Квест для невесты

Одностраничное статическое веб-приложение для городского квеста на девичник.

## Технологии

- Vanilla HTML, CSS и JavaScript — без сервера и базы данных.
- Скрипты на встроенном Node.js — только для локальной разработки и подготовки папки для публикации.
- Папка `dist/`, создаваемая сборкой, готова к размещению на любом статическом хостинге: GitHub Pages, Netlify, Cloudflare Pages, S3 и т. п.

## Локальный запуск

Требуется Node.js 14+ (лучше актуальная LTS-версия).

```bash
npm install
npm run dev
```

Скрипт выведет локальный адрес, обычно `http://localhost:5173`.

## Проверка и сборка

```bash
npm run check
npm run build
npm run preview
```

`npm run build` создаёт самодостаточную статическую папку `dist/`. На хостинг загружается её содержимое, а не исходники проекта.

## Запланированная механика геолокации

Браузер запросит разрешение на геолокацию только по действию участницы. Для каждой точки маршрута приложение будет хранить координаты и допустимый радиус (например, 80 м), а затем вычислять расстояние на устройстве.

Важно: поскольку приложение полностью статическое, проверка местоположения выполняется на клиенте и не защищена от намеренного обхода. Для дружеского квеста это обычно уместно; если понадобится защита результатов или секретных ответов, потребуется отдельный серверный компонент.
